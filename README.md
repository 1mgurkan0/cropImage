# SEO & Image Toolkit

Web geliştiricileri ve site sahipleri için hazırlanmış, tarayıcı üzerinden çalışan basit bir SEO ve görsel işleme araç seti. Tek panel altında 6 farklı araç sunar.

## Özellikler

- 🖼️ **Image Compressor** — Görselleri kalite kaybını minimumda tutarak boyutça küçültür
- 🔄 **Format Converter** — Görselleri farklı formatlara (JPG, PNG, WebP vb.) dönüştürür
- ✂️ **Image Cropper** — Görsellerde istenen alanı kırpma imkanı sağlar
- 🔗 **Broken Link Checker** — Bir sitedeki kırık (404) linkleri tarayıp listeler
- 📊 **SEO Analyzer** — Sayfaların temel SEO metriklerini (meta etiketler, başlıklar vb.) analiz eder
- 🔤 **Word/Character Counter** — Girilen metnin kelime ve karakter sayısını hesaplar

## Kullanılan Teknolojiler

- **Backend:** PHP (Symfony)
- **Frontend:** JavaScript
## Notlar

Bu proje, sık kullanılan SEO ve görsel düzenleme ihtiyaçlarını tek bir yerde toplamak amacıyla geliştirilmiştir.
